## Кейс 1. Поиск нетипичного поведения заявок на закупку

Итог: 66 строк по 56 процессам. Восемь типов отклонений, критерии и пороги описаны в `кейс1/case1-solution.md`.

Проверка:

```bash
cd кейс1
pip install pandas
python analysis.py --input students.csv --output anomalies.csv
```

## Кейс 2. Восстановление процесса по журналу событий

Итог: 8 вариантов маршрутов, покрытие 100 процентов, основной маршрут 56,7 процента, схема в `кейс2/schema.png`.

Проверка:

```bash
cd кейс2
pip install pandas
python analysis.py --input students.csv --variants variants.csv --transitions student_transitions.csv
```

## Данные

Журналы `students.csv` выдаются в задании и в репозиторий не входят: положите файл рядом со скриптом или передайте путь через параметр `--input`.

AI-ассистент применялся для написания скриптов анализа, построения схемы и черновиков отчётов. Все числа и выводы перепроверены повторным расчётом на исходных файлах.
